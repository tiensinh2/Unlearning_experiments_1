# Principles for a Representation-Level Class-Unlearning Experiment (generic)

Use this as the spec when writing notebooks for any new benchmark. It contains no dataset-, model- or paper-specific numbers: choose values yourself, run a small sweep on **validation**, and log everything.

---

## 1. Core idea

- **Class unlearning:** remove the influence of the forget classes from a trained model without retraining from scratch, while keeping the rest of the model's behaviour.
- **Do not trust output accuracy alone.** A model can hide a class by changing only its classifier while the encoder features still separate that class. Evaluate at the **output level** and at the **feature level**.
- **Reference models:** the *original* model, and the *oracle* (retrained from scratch on the retain data only). The oracle's own feature-level forget accuracy is usually **not** zero (features transfer between classes), so compare against original, oracle and the same method without the feature-level mechanism. Do not hard-code "forget accuracy ≈ 0" targets for features.

---

## 2. Data

1. Three disjoint splits: **train / val / test**. If there is no validation split, carve it out of train (stratified, fixed seed). Test stays untouched until the final report.
2. Choose forget classes; derive `train_f, train_r, val_f, val_r, test_f, test_r` by class membership. Persist indices and the seed, and reuse them in every notebook.
3. Use several forget-class combinations and seeds; report mean ± std.
4. `val_f` must be large enough for the metric to be meaningful (one sample changes accuracy by `1/N_val_f`).
5. Validation is used only for model selection and stage control. It is never used to train a probe or any model being evaluated.

---

## 3. Metrics (identical in every notebook)

- All accuracies in `[0, 1]`; assert the range before computing any score.
- **Output accuracy:** argmax of logits.
- **Linear probe (LP):** train a *fresh* linear classifier on frozen training features of all classes (deterministic solver, fixed seed); evaluate on the held-out split.
- **Nearest class center (NCC):** class means from training features of all classes; predict the nearest mean.
- Feature extraction: encoder in `eval()`, `no_grad`, no augmentation, features cached per checkpoint.
- Evaluate on **val** during selection and on **test** only for the final report.
- **Illusion gap:** `max(LP_f − Output_f, 0)` and `max(NCC_f − Output_f, 0)`.

---

---

## 5. Shared loop for 04a, 04b, 04c: validation-driven continued training

All three notebooks use the same engine. Training continues in short **stages**; each stage resumes from the **best checkpoint so far** (not the last one), usually with a smaller learning rate. Every epoch is judged on **validation only**.

```python
best = None
state = start_checkpoint
for stage in stages:
    if best: state = restore(best.checkpoint)        # continue from best, not last
    no_gain = 0
    for epoch in range(stage.max_epochs):
        train_one_epoch(state, trainable=variant.trainable, lr=stage.lr)
        m = evaluate(state, split="val")             # never test here
        ok = variant.eligible(m)                     # e.g. retain-accuracy constraint
        s = variant.score(m)
        if ok and (best is None or s > best.score + min_delta):
            best = Snapshot(score=s, checkpoint=save(state)); no_gain = 0
        else:
            no_gain += 1
        log(stage, epoch, m, s)
        if no_gain >= stage.patience: break          # move to next stage
    if variant.stop(best.metrics): break             # optional early stop
final = best.checkpoint
report_test(final)                                   # exactly once
```

Shared rules:
- A few short stages, each with `max_epochs`, `patience`, and a learning rate (later stages smaller). Pick values with a small validation sweep.
- `min_delta` must be at least the metric's resolution (about `1/N_val_f`); anything smaller is noise.
- **Eligibility constraint:** a checkpoint can be selected only if `Acc_retain_val >= Acc_retain_val(original) − δ`.
- **Generic score:** a weighted sum of erasure terms and a retain term, all in `[0, 1]`, for example `w_e·(1 − erasure_acc) + w_r·Acc_retain`. State the goal explicitly: *go below the oracle* (reward lower feature-level forget accuracy) or *match the oracle* (penalize `|acc_f − acc_f_oracle_val|`, using oracle metrics from validation).
- Log per-epoch validation metrics and stage transitions; save every snapshot's config.
- Test is evaluated **once**, on the final selected checkpoint.

### What differs per variant

| | 04a: static | 04b: post-hoc classifier | 04c: adaptive blending |
|---|---|---|---|
| **Start from** | original | best checkpoint of 04a | original |
| **Trainable** | encoder; classifier head tied to class-mean features, rebuilt each epoch and frozen | classifier head only; encoder frozen | encoder and head; effective head `W = (1−α)·W_learned + α·W_class_mean` |
| **Score (val)** | feature-level erasure (`1 − LP_f`, `1 − NCC_f`) + retain accuracy | low output forget accuracy + retain accuracy (feature metrics are unchanged by construction) | as 04a, plus a penalty on the illusion gap |
| **Extra checks** | retain constraint | encoder unchanged (below) | `α = clamp(gap / scale, 0, 1)` with `gap = max(NCC_f − Output_f, 0)` |
| **Stop** | patience per stage | patience per stage | patience, or val `NCC_f` within a tolerance of the oracle's **val** value |

Notes:
- **04b encoder freeze:** set `requires_grad=False` **and** `encoder.eval()` (BatchNorm statistics otherwise keep changing the features); put only head parameters in the optimizer. Verify invariance directly: encoder `state_dict` identical (or equal hashes) and near-zero feature difference on a fixed validation batch. Do not assert on probe-accuracy differences (probe noise). Because the loop is validation-driven, there is no separate "choose `k` epochs" step. Report before and after: lowering output forget accuracy here is classifier suppression, not extra erasure.
- **04c gap sign:** the gap must be large when the output is suppressed but the representation still separates the class, i.e. `NCC_f − Output_f`. The reverse subtraction gives a negative number and clamps `α` to 0. The oracle target for stopping comes from **validation** metrics over several oracle seeds, with a tolerance floor of a few samples so a near-zero spread cannot block stopping. Never use test numbers for stopping.

---

## 6. Sanity checks (relative, no fixed thresholds)

| Model | Expect |
|---|---|
| Original | Output, LP and NCC all high and close to each other, on retain and forget classes. |
| Oracle | Output forget ≈ 0 (if the head keeps all outputs); LP/NCC forget above 0. Record as the reference. |
| Baselines (no feature-level mechanism) | Retain close to original. Output forget is low for most methods but not guaranteed. Check that the illusion gap exceeds a margin you choose, per method. |
| 04a / 04c | LP/NCC forget below the same method's baseline; retain within `δ` of original; output forget may remain above 0. Do not require "below oracle" as pass/fail. |
| 04b | Output forget lower than its 04a starting point; encoder identical; LP/NCC unchanged. |

---

## 7. Reporting

- Mean ± std over forget combinations and seeds; each metric on retain and forget subsets; deltas to original and oracle; run time.
- **Fairness:** give baselines the same epoch budget and the same validation-based selection as the variants, or run everything with fixed epochs. State which you did.
- Test is evaluated once per reported checkpoint. Every number in a table must come from an executed run.

---

## 8. Porting checklist for a new benchmark

1. Record number of classes, input size, backbone, feature dimension.
2. Train the original with validation-based early stopping; record its accuracies.
3. Pick forget combinations; confirm `N_val_f` is large enough.
4. Many classes: cache features and fit the probe on cached features.
5. Tune learning rates per method on validation with a small sweep.
6. Fix seeds (split, training, probe) and log all configs.
7. Scope: this covers **class** unlearning. For random-sample forgetting, class-level LP/NCC forget accuracy is not meaningful and needs a different evaluation.

---

## 9. Rules for autonomous agents

1. Never evaluate test during training or stage control.
2. Assert accuracy range `[0, 1]` before scoring.
3. Feature extraction: `eval()` + `no_grad` + no augmentation.
4. Reuse the persisted split; assert train/val/test are disjoint and no forget-class sample sits in a retain subset.
5. Verify frozen modules with `state_dict` comparison, not only `requires_grad`.
6. Do not invent numbers; results come from runs.
